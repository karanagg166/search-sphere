# Search Sphere integration

The production candidate preserves `DocumentExtractor(HostedLayoutRecognizer())`,
then `TextCleaner`, then `apps/api/src/services/package_chunking.py`. The bridge
normalizes the existing blocks without re-extraction, injects the guarded exact
Cohere tokenizer and feeds existing embedding/atomic publication. Build the
canonical API Dockerfile from repository root with the core package installed.
There is no engine-selection environment variable.

Complete source objects and normalized views are retained in `document_evidence`;
chunk provenance links stable source IDs, page geometry, hierarchy, sentence IDs,
row ranges and private crop IDs. Existing owner authorization and deletion apply
to these objects and vectors. Model numbers/arrows remain review-required.

Other projects install this library independently and inject approved providers;
this does not restore Quick-Clinic/Exam Arena HTTP chatbot endpoints.
